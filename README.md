# 🌍 City Weather Tool - Final Travel Safety Checker

A real-world travel safety tool built with Python. Get current weather, air quality alarm, and 5-day forecast for ANY city worldwide.

### Features
- **Current Weather:** Temperature, condition, humidity, wind speed
- **Air Quality Alarm:** 1=Good (Juba) to 5=Very Poor (Dakar/Beijing) 
- **5-Day Forecast:** Plan your week ahead
- **Any Location:** Nairobi, Juba, Dakar, Kampala, worldwide

### Setup
1. Clone: `git clone https://github.com/Olang7/Ai-masterclass.git`
2. Install: `pip install requests python-dotenv`
3. Create `.env` file with: `OPENWEATHER_API_KEY=your_key_here`
4. Get free API key at openweathermap.org

### Usage
python week11/final_day3_travel_info.py
Enter city: Juba

### Example
Weather in Juba: 32C, clear sky, humidity 45%
Air Quality: 1/5 - Good ✅
