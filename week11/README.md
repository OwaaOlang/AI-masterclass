# Week 11 - Travel Tool: Air Quality (Option D)

### Kampala Air Quality Checker

This tool helps travelers check if air is safe in Kampala before visiting.

**Main File:** `option_D_air_quality.html`

**What it does:**
- Gets real-time Air Quality Index for Kampala (Lat: 0.3476, Lon: 32.5825)
- Shows AQI level 1-5 with colors
- Breaks down pollutants: PM2.5, PM10, O3, CO, NO2, SO2
- Gives travel advice based on air quality

**How to run:**
1. Double-click `option_D_air_quality.html`
2. Put your OpenWeather key in the code
3. Refresh browser

**API Used:** OpenWeather Air Pollution API
`http://api.openweathermap.org/data/2.5/air_pollution?lat=0.3476&lon=32.5825&appid=YOUR_KEY`

**Security:** Key is hidden with placeholder `PUT_YOUR_OWN_KEY_HERE`
